# samples

Small, non-canonical dataset folders built from a few days of raw SIRTA data, for testing the
release's fetch -> preprocess -> select -> infer pipeline end to end. Not redistributed here
(gitignored, same as the full `sirta_2023_image64-localtime_ICHP-daytime-dhi/` folder).

**Exception: `synthetic_2023/` is redistributed** (tracked, not gitignored). It contains no SIRTA
observations -- its images are generated by a diffusion model and its irradiance values are invented -- so
none of the reasons the real samples aren't redistributed apply to it. See `synthetic_2023/README.md`.
